## Paste-ready short description

WorldSpeak is an accessible communication system that transforms user-approved visual context and personal communication needs into deterministic English/Tamil sentences, with speech controlled by the user. A guest essential board works offline after preparation. Local video supports manual frame and region selection; personal pictograms bind a local image to the user's exact words. Object confirmation, intent selection, exact sentence preview and a fresh Speak gesture remain separate decisions.

A server-only Meta integration uses authenticated, owner-scoped jobs, integer micro-USD reservations, lease fencing, one-shot authorization and consent-scoped temporary media. One real Standard Muse Spark 1.3 chair generation succeeded historically; its application persistence initially failed, was subsequently repaired, and is now regression-tested with reconstructed fixtures. SAM 3.1 provider integration and pixel-mask rendering are implemented and synthetic-fixture tested, with no real SAM generation. The public release keeps generation disabled. Evaluation is synthetic and deterministic, not a real-model accuracy measurement. Tamil wording and native speech quality remain pending independent review. No diagnosis or treatment is offered.
