## Boundaries inspected

| Boundary | Current implementation and evidence | Acceptance limit |
|---|---|---|

| Cookie-authenticated mutations | `lib/auth-security.ts` rejects cross-site Fetch Metadata and requires exact configured Origin for non-GET/HEAD/OPTIONS methods. JSON streaming is bounded to 16 KiB before parsing. | Not an application-wide abuse limiter; do not open paid routes without their existing budget/permit fencing. |
| Callback / refresh | Callback exchanges code server-side, then exact local-path allowlist. Proxy refreshes with `getUser`, preserves response cookie options and marks responses private/no-store; protected handlers independently reverify. | Production Secure/SameSite/HttpOnly behavior and elapsed-time expiry were not freshly observed. Logout must not be described as instantaneous invalidation of every already-issued JWT. |
| Account deletion | Identity DELETE requires exact confirmation, password proof, same-owner reauthentication and server-only admin client; no pre-erasure on provider failure. Content/data erasure uses owner-derived RPC. | OAuth-only identity reauthentication remains unsupported. Missing service-role key returns 503; no password bypass allowed. Source comment claiming identity removal unavailable is outdated relative to implemented password flow. |
| RLS / grants | Migrations enforce owner-scoped database operations; 009 removes retained `service_role` EXECUTE on renamed legacy submission while supported definer wrapper retains its owner call. | Inference / billing | Strict provider contracts, durable worker leases/idempotency, integer-microUSD reservations, one-shot scope and uncertain-dispatch fences are in worker/inference packages. | No new generation authorization. | Pictograms / video | Local images validate file/header/dimensions before bounded decode, abort/revoke object URLs; gallery is memory-only. | Secrets / offline cache | Public-key names are explicit; privileged admin/worker/provider keys are server-only. Offline board caches public generated assets, not private API responses. | Final artifact/host environment and client resources need independent secrets/network checks after deployment. |

## Concrete follow-up findings

1. **Speech completion/error feedback gap (source-confirmed, runtime impact not newly reproduced):** `BrowserSpeaker` supplies no `onend`/`onerror` callbacks; `SpeechGateway.speaking` becomes true on enqueue and false only on explicit Stop. Composer reports “Speaking” on enqueue, not actual audio completion. Add bounded terminal-state/error callbacks and fake-synthesis regressions before claiming reliable speech-failure recovery. Do not treat a status string as audible success.
2. **Voice availability race — repaired in this working tree:** original adapter could leave `utter.voice` unset after native voice disappearance. `BrowserSpeaker` now requires exact selected name and locale at the final boundary before creating/enqueueing an utterance. Missing/relabeled voices raise `VoiceUnavailableError`; the gateway maps only that error to its existing actionable `no-voice` result, while preview returns false. The consumed gesture cannot be replayed. `speech.test.ts` has four native-boundary cases (missing voice, same-name wrong locale, gateway disappearance/replay/preview, exact Tamil voice dispatch); all 10 speech tests passed. This uses a stubbed native synthesis boundary, not real-device audio. Completion/onerror reporting above is still open; it was not broadly refactored.
3. **Existing acceptance gaps:** controlled inbox delivery/recovery, OAuth-only account deletion, real hosted search/replay/preferences, active-token/session-expiry behavior and production callback/cookie checks remain open. These are explicit limitations, not newly discovered authorization bypasses.

No critical exploit or confirmed ownership bypass was demonstrated in this bounded review. That statement is not a comprehensive security certification. Preserve private deny-all RLS/advisor notices and actual known Free-plan limitations rather than claiming all advisors are clean.
