# Actual public guest demo recorder

`node tooling/demo/record.mjs` records the hardcoded canonical HTTPS application using real Chromium, no results mocks and no speech stub. It accepts no target URL or credentials. The dedicated PR workflow installs the pinned workspace/browser and captures a WebM, source SHA, observed asset path, network scope, captions and fixture hash. ffprobe must verify a nonempty ≤180-second artifact. A failed recorder uploads **partial evidence**, never a completed demo.

Footage: essential English/Tamil exact previews → explicit Speak/Stop; genuinely decoded original local synthetic WebM/manual frame-region selection → own words/composer; local MIT-repository synthetic PNG → assigned meaning/composer; prepared static board with only this browser context offline. An editorial caption overlay labels CI voice/audio limitations, manual/synthetic media and historical Spark failure/repair; it supplies no detections, masks or model responses. Playwright's video has **no recorded audio**, so human narration/system-audio capture and native Tamil review remain required for the final portal asset.

Network routes reject external origins, API/Auth paths and all non-GET/HEAD methods instead of manufacturing responses. Any forbidden attempt fails artifact acceptance. No account, provider, media upload, model dispatch or paid retry is authorized. The original local WebM and PNG are already public repository fixtures, not personal images. The browser process is bounded to 170 seconds; the workflow is bounded to ten minutes.

The recorder code SHA and observed public asset path are recorded separately: the script must never pretend its PR SHA proves the deployed app SHA.
